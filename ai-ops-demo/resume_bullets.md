# 简历项目 STAR 写法（直接复制修改）

## 项目名称建议
**AI 驱动的新零售用户运营提效 Demo**（个人项目 / 独立实践）

> 一句话定位：模拟连锁咖啡 O2O/B2C 场景，用「SQL + Python + 大模型 + Agent 工作流」跑通“用户分层 → 策略制定 → AI 文案生成 → 评论洞察 → 日报自动化”完整链路。

## 推荐放在简历的 4 条 Bullet

- **业务分析**：使用 SQL 和 Python（pandas）对 800 名用户、4000 条订单进行 RFM 用户分层，识别重要价值、重要唤回、流失风险等 6 类人群，并输出针对性运营策略。
- **AI 内容生成**：调用大模型 API 按人群和渠道批量生成营销文案，设计统一 Prompt 模板与人工审核流程，内容产出效率提升约 70%。
- **用户洞察**：构建用户评论情感分析与业务问题分类流程，自动生成评论洞察报告，将高频负面问题定位到“配送/价格/服务”等具体环节。
- **Agent 工作流**：参考 LangChain/Dify 思路设计运营自动化工作流，自动汇总销售数据、识别重点人群并生成运营日报与行动建议，人工准备时间由数小时缩短至分钟级。

## 面试可讲的量化口径（按真实数据调整）
- 内容产出：X 条/天 → Y 条/天，提效 Z%
- 用户分层：覆盖 X 万用户，召回率提升 X%
- 评论处理：人工分析 X 小时 → 自动生成报告 X 分钟
- 日报自动化：准备时间 X 小时 → X 分钟

## 技能栏写法
SQL、Python（pandas）、数据分析、RFM 模型、大模型 API、Prompt 工程、Dify/LangChain 工作流设计
